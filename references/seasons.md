# 基准身份固定，季节只切换衣服

## 规则

4号世文富优先使用用户2026-11-19新照，详见 [新身份](identity-401-4.md)；其他编号继续旧版身份。所有401人物的脸型、五官、眼睛、眼镜、发型、肤色、年龄外观及体型，固定采用本人的当前基准主身份和补充视角（4号新照优先）。旧资料未展示的正脸/眼部细节不凭空补造。冬季照片只负责服装，低清脸部不能用于覆盖基准身份。也不采用过去生成图作真人参考。

- 没有季节词或含冬/冬季：基准身份 + 冬装。
- 含春、秋、春秋：基准身份 + 旧服装。
- 冬季与春秋要求冲突时澄清；每次重新解析。
- 已有人物不换脸、不换衣；仅新增人使用上述组合。

## 文件与工具参考顺序

`private/roster.json` 外层身份字段与 `seasonal_references.spring_autumn` 是身份基准。所有 winter.identity_source / identity_box / identity_references 已同步当前身份基准（4号新照，其余旧照）；winter.clothing_source / clothing_box 才指向冬季衣服。不要再用冬季照片里的低清脸和眼睛生成身份。

`private/identities/401/*.png` 是主身份；对应 -ref-N 是旧补充视角。`private/identities/401/winter/` 和 `401-winter-identity-atlas.jpg` 是兼容入口，内容已替换为基准身份。旧图片不代表要穿旧上衣，参考角色须在提示词中明确。

`prepare_references.py --room 401 --ids 2,3 --season winter --out <目录>` 输出基准身份板、适用的当前补充身份板和冬装衣服板。人物脸、眼镜、发型以基准身份板优先，服装板只负责衣服。冬装衣服裁图避开头部；不要为取衣服默认发送整张冬季场景。如果确需场景图辅助定位，明确其中的脸不参与身份合成。不要把图上的手机品牌、日期、定位、水印复制到结果。
