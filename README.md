# 打卡skill · 401秋冬版

最新版：2026-11-19。新增世文富8张用户确认照片与清晰侧脸身份，所有季节优先该新身份，服装维持既有季节规则。包含冬装切换、旧版面部参考、李涛工位间隔以及李涛/耿芳东人物比例校准。

公开仓库：https://github.com/1142765505/401daka-skill-winter

适用于支持技能与图像编辑工具的 Codex。其他客户端是否支持本地技能取决于客户端能力。


Codex 技能，技术名 `daka-skill`，中文调用“使用打卡skill”。401 编号1–10，403编号1–4。

| 输入 | 命令示例 | 行为 |
|---|---|---|
|一张401照片|使用打卡skill，401增加3|3号已存在则跳过并提示，否则新增|
|一张401照片|使用打卡skill，401增加3、4、5|只补缺席编号，保留原有其他人|
|无照片|使用打卡skill，401增加3、4、5|重建401场景，仅出现3/4/5|
|无照片|使用打卡skill，增加全部|默认401，生成1–10全员|
|有/无照片|使用打卡skill，403增加4|有底图只补缺席4号；无底图仅生成4号|
|无照片|使用打卡skill，403增加全部|生成403的1–4全员|

每次需编辑时只生成1张结果（结果.png），保存到技能目录 `output/`；全部目标已存在则不重复生成。输出为AI合成图，不提交考勤。

## 安装及本地照片

在 Codex 中发送：

> 使用 skill-installer，从 https://github.com/1142765505/401daka-skill-winter 安装根目录技能，安装名为 daka-skill。

也可在终端安装（需 Git）：

```sh
git clone https://github.com/1142765505/401daka-skill-winter.git "$HOME/.codex/skills/daka-skill"
```

安装后重启 Codex，让其读取新技能。已通过此仓库安装的用户，可在技能目录执行 `git pull --ff-only` 更新。随后上传底图，发送 `使用打卡skill，401增加2、3`；默认冬装，追加 `春季` 或 `秋季` 使用旧服装。姓名示例：`使用打卡skill，生成耿芳东、李涛`。

仓库随附已生成的概览、身份和服装裁图，安装即可读取参考。首次运行 Python 脚本时安装下方依赖；仅在更换原始照片或需要重建参考时运行 `build_library.py`。

将仓库安装为 `~/.codex/skills/daka-skill`，或从该目录链接到本项目。仓库包含技能、脚本、姓名对应表和用户授权公开的401/403原始参考照片。生成结果和密钥不入库。姓名表见 references/people.md。

参考元数据在 references/private/（兼容旧名）。必要时运行 build_library.py 重建概览与裁图；401的7–10可仅露头发或额头，1号羊沐阳、4号世文富采用修订主侧脸和补充视角，详见 references/identity-401-1-4.md。

这是一套参考引导流程，不是微调模型；参考中的遮挡、远景或侧背面信息不能扩充成未经支持的清晰正脸。

```sh
python -m pip install -r requirements.txt
python scripts/build_library.py
python scripts/plan.py --command '使用打卡skill，401增加3、4、5' --has-input --present 3
python -m unittest discover -s tests
```

`--present` 和 `--uncertain` 必须来自 Codex 实际看图，脚本不做人脸识别。工具依赖为可用的图像编辑/生成能力；没有内置工具时会明确报告。

开源代码采用 MIT；姓名对应表和参考照片已获用户许可随仓库公开；MIT适用于代码，不额外授予照片中人物的肖像使用权。生成结果不进入仓库。文件名是照片索引，不是人物编号。

9号岳松涛已重新筛选15号主参考及17/20号补充，生成优先保持原工位的头发/额头遮挡，见 [9号修订](references/identity-401-9.md)。

## 冬季默认（2026-11-18更新）

所有季节使用同一身份基准：4号世文富优先2026-11-19用户新照，其余仍旧版401照片。401无季节词或含“冬季”时，仅衣服取自401照片冬季；含“春”“秋”“春秋”时使用旧服装。支持 `使用打卡skill，冬季401增加2、3`、`使用打卡skill，401增加2、3，春季`。403维持旧库，不跨房间借衣服。

冬季原图当前14张，全部纳入参考索引。1–5号已有冬装参考；7/8/10保持原遮挡、头部采用旧身份；6号缺已确认冬装参考（172右端站立人物已被用户排除），需新增6号时先补资料；9号按用户明确要求不更新，保留旧参考，不因缺冬季照片阻塞生成。已有人员仍按原规则跳过。详细情况见 references/seasons.md。

`python scripts/prepare_references.py --room 401 --ids 2,3 --season winter --out <目录>` 生成旧身份板与冬季服装板；春秋用 `--season spring_autumn`。技能修改不自动生图。之前20261105安装包是历史快照，不包含本次更新。

## 低清冬季人脸修正

人物脸型、眼睛、眼镜、发型与体型统一用当前基准主身份及补充视角（4号优先2026-11-19新照，其余旧版）；旧低清冬季图片只取衣服，不再取脸。参考准备脚本在冬季模式也读取旧身份裁图，独立输出避开头部的冬装裁图。计划中 identity_reference_set 与 clothing_reference_set 分别记录身份和服装来源。已有人物保持原样，9号保留旧参考的例外继续有效。本次仅修改规则、参考和脚本，未生成示例图片，也不承诺生成模型必定还原所有面部细节。

## 李涛位置纠正

401工位顺序为“1号 → 一个保留无人空位 → 2号李涛”。李涛不得坐入中间空位；此关系适用全部季节。生成前定位及独立复核均需检查间隔，不能继续沿用此前错误的辅助框/生成图。只更新技能时不自动重新生成。

## 人物比例修正

李涛、耿芳东生成前须依据本次原椅/桌沿/同景深人物建立尺度范围，分别控制头高、头宽、肩宽及坐姿躯干；不采用身份参考板大小或固定缩放百分比。生成后统一坐标尺度复核，人物仍偏大判FAIL。李涛过大遮住中间无人座位证据时不能判通过。保持臀部在原椅座面，不移动家具迁就人物；详见 references/person-scale-401.md。仅修改技能，不自动生成示例。
